# ECO TWIN ML — AI-Powered Environmental Digital Twin

An end-to-end full-stack environmental intelligence platform that models a user's lifestyle as a dynamic **Environmental Digital Twin**, predicts monthly carbon emissions ($\text{kg CO}_2\text{e}/\text{month}$) using **Random Forest Regression**, classifies environmental risk using **Random Forest Classification**, detects unusual consumption spikes with **Isolation Forest**, projects future emissions with time-series forecasting, explains model predictions via feature attribution, and generates downloadable **PDF Sustainability Reports**.

---

## 1. Architecture & Data Flow

```text
USER INPUT (6-Section Carbon Calculator)
   ↓
FRONTEND (Chart.js + Centralized Fetch API Module)
   ↓
REST API (/api/* with JWT Authentication & Input Validation)
   ↓
DATABASE & MACHINE LEARNING PIPELINE
   ├── RandomForestRegressor (Carbon Footprint Prediction + 8-Category Breakdown)
   ├── RandomForestClassifier (4-Tier Eco Risk Classification)
   ├── IsolationForest (Unsupervised Anomaly Detection)
   ├── Time-Series Forecaster (3M, 6M, 12M Carbon Trajectory)
   └── Explainable AI (Feature Importance & Marginal Perturbation Attribution)
   ↓
ENVIRONMENTAL DIGITAL TWIN & PDF REPORT ENGINE
   ↓
FRONTEND VISUALIZATION (Dashboard, My Twin, Scenario Lab, What-If Simulator, Reports)
```

---

## 2. Core Features

1. **Authentication (`/api/auth/register`, `/api/auth/login`, `/api/auth/me`)**:
   - Password hashing (`PBKDF2-SHA512` / `bcrypt`), signed `HS256` JWT tokens, protected API routes, and an optional labeled development demo seed account (`demo@ecotwin.org` / `EcoTwin2026!`).
2. **6-Section Carbon Calculator (`/api/calculator/analyze`, `/api/calculator/predict`)**:
   - `01 Personal Profile`, `02 Transportation`, `03 Energy Consumption`, `04 Food & Lifestyle`, `05 Waste Management`, `06 Lifestyle & Others`, plus expandable `Advanced Environmental Data`.
   - Includes a live **AI Analysis Preview** card with Chart.js visualization, model metrics, and explicit `"Model confidence: Not available"` notice for non-parametric regression ensembles.
3. **Environmental Intelligence Dashboard (`/api/dashboard`)**:
   - Displays Current Footprint, Eco Score, 6-Month Future Prediction, Anonymous Community Percentile, Emission Breakdown, Carbon Footprint Forecast, *"What is affecting my score?"*, Lifestyle Optimization, IsolationForest Anomaly Detection, Goal Progress, Recent Achievements, and 1-click PDF Report export.
4. **Environmental Digital Twin (`/api/twin`)**:
   - Visualizes an interactive ecological biosphere (solar roof, forest canopy offset trees, transit vehicle, wind energy, recycling loop, air clarity index) along with Twin Evolution, Composition, AI Twin Insights, and live Twin What-If simulation.
5. **Explainable AI Analysis (`/api/analysis`, `/api/analysis/explain`)**:
   - Answers *"Why is my carbon footprint high?"* using actual ML feature importance weights and local marginal $\text{kg CO}_2\text{e}$ contributions across `Transportation`, `Energy`, `Food`, `Waste`, `LPG`, `Water`, `Lifestyle`, and `Other`.
6. **Time-Series Forecasting (`/api/forecast`)**:
   - Interactive historical window filters (`1M`, `3M`, `6M`, `12M`) and forecast horizons (`3 Months`, `6 Months`, `1 Year`) with uncertainty bounds and limited-history notices.
7. **What-If Simulator & Scenario Lab (`/api/simulator/what-if`, `/api/scenarios`)**:
   - Real-time counterfactual simulation across 8 lifestyle sliders/selects, plus multi-scenario creation, persistence, deletion, and Chart.js comparison matrices.
8. **Goals, History, Anomalies, Recommendations, Achievements, PDF Reports, Anonymous Community & Settings**:
   - Complete CRUD and analytics workflows backed by real API endpoints.

## 4. Running the Application

### Option A: Unified Full-Stack Server (Port 3000)

```bash
npm install
npm run dev
```

- Application UI: `http://localhost:3000`
- Interactive OpenAPI / Swagger Docs: `http://localhost:3000/docs`
- Health Check: `http://localhost:3000/api/health`

### Option B: Python FastAPI Backend + Standalone HTTP Server

```bash
cd backend
pip install -r requirements.txt
python generate_dataset.py
python train_models.py
uvicorn app.main:app --reload --port 8000
```

In a second terminal:

```bash
cd frontend
python -m http.server 5500
```
